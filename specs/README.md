# Specs

This directory stores feature-level product and architecture specs for Meeting Survivor.

## Feature specs

- [`001-cli-obs-blackhole-mvp.md`](001-cli-obs-blackhole-mvp.md): the completed first implementation track, using the Python CLI, OBS Virtual Camera, and BlackHole.
- [`002-native-macos-app.md`](002-native-macos-app.md): the active second implementation track, moving toward a native SwiftUI app, typed Python backend IPC, CoreMediaIO virtual camera, and CoreAudio virtual microphone.

## Working rule

Treat each spec as a feature track. Create implementation tickets in `../tickets/` for narrow slices of the active spec, and work one ticket at a time.
